# 🎤 Voice Assistant for Android

A powerful voice-controlled assistant that can control your Android device using natural voice commands.

## ✨ Features

### 📲 App Control
- Open any app: "Open Chrome", "Open WhatsApp"
- Close apps: "Close app"
- Download apps: "Download Spotify"
- Clear background apps: "Clear all apps"

### 📜 Navigation
- "Scroll up/down/left/right"
- "Go back"
- "Go home"
- "Recent apps"

### ✍️ Text Operations
- "Type hello world"
- "Copy" / "Paste"
- "Select all"
- "Click [button name]"

### 📞 Communication
- "Call Mom"
- "Send message to John saying hello"

### ⏰ Time Management
- "Set alarm for 7:30"
- "Set timer for 5 minutes"
- "Start stopwatch"

### 🌐 Web
- "Search for weather"
- "Open website google.com"

### 🔧 System
- "Volume up/down"
- "Flashlight on/off"
- "Take screenshot"
- "Open settings"

## 🚀 Setup

1. Clone the repository
2. Open in Android Studio
3. Build and install on your device
4. Grant all permissions
5. Enable Accessibility Service
6. Say "Hey Assistant" to start!

## 📋 Required Permissions

- Microphone (for voice recognition)
- Phone (for making calls)
- SMS (for sending messages)
- Contacts (for finding contact numbers)
- Camera (for flashlight)
- Accessibility Service (for device control)

## 🗣️ Wake Words

- "Hey Assistant"
- "Hi Assistant"
- "Okay Assistant"

## 📱 Minimum Requirements

- Android 7.0 (API 24) or higher
- Microphone
- Internet connection (for speech recognition)
